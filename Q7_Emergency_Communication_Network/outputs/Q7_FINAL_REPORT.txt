MOBILE COMPUTING ASSIGNMENT 3
Q7: EMERGENCY COMMUNICATION NETWORK
=======================================================

1. NETWORK ARCHITECTURE
----------------------------------------
The proposed network consists of ambulances, police vehicles, rescue teams, medical personnel, drone relays, gateway vehicles and a Command Centre.

2. MOBILE IP IMPLEMENTATION
----------------------------------------
Mobile IP registration and gateway handoff were implemented using a Home Agent and two gateway Care-of Addresses.

Microwave end-to-end delay: 65 ms
Satellite end-to-end delay: 295 ms

3. AODV ROUTING
----------------------------------------
AODV route discovery, RREQ broadcasting, RREP route establishment, data forwarding and RERR failure notification were implemented.

7. CONCLUSION
----------------------------------------
1. The emergency network uses mobile nodes, drone relays and gateway vehicles.
2. Mobile IP maintains the mapping between the permanent Home Address and current Care-of Address.
3. AODV establishes routes on demand using RREQ and RREP messages.
4. RERR reports broken links and allows affected routes to be rediscovered.
5. Alternative gateway connectivity helps restore communication after failures.
6. Microwave backhaul provides lower delay than satellite under the configured assumptions.
7. Network partition recovery requires restoring at least one gateway connection.
8. Redundant mesh paths improve emergency communication availability.

8. SIMULATION LIMITATIONS
----------------------------------------
This implementation is an analytical Python network simulation using NetworkX. Performance metrics are calculated using configured delay and packet-loss assumptions. It does not model physical radio propagation, interference, congestion or real wireless packet captures.
